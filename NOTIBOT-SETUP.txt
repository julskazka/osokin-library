БИБЛИОТЕКА ДЛЯ NOTIBOT

1. Создайте страницу в Notibot с размещением собственного HTML.
2. Вставьте всё содержимое notibot-library.html и сохраните. Внешние файлы не нужны.
3. Откройте страницу из Notibot: надпись «Библиотека подключена к Notibot» подтверждает обмен с родительской страницей. Проверьте бесплатный эфир, платный эфир, возврат и фильтры.
4. Проверьте режимы Inline/App/Portal, которые используете. Мост передаёт высоту автоматически. При открытии вне iframe работают обычные ссылки; если Notibot предоставляет SDK напрямую, его подключённое состояние также учитывается.

Сохранены исходный дизайн, фотография, 24 эфира, ссылки и порядок. Мост версии 1.1.0 взят из переданного архива без изменения. Используются только публичные методы. Формы не добавлены; идентификаторы не сохраняются и профиль не выводится.

В iframe и подключённом Notibot тестовые покупки отключены. Без серверной проверки платные эфиры ведут на purchase_url; существующие покупки нужно проверять на стороне Notibot. Мост НЕ умеет получать оплаченные заказы. ID пользователя и произвольные поля NOTIBOT_INIT не считаются подтверждением покупки. Вне Notibot остаётся демонстрация с тестовыми статусами.

Для следующего шага нужна официальная документация/API/поддерживаемый механизм проверки оплаченных заказов и подписанного контекста. Нижеописанное не заменяет такую интеграцию.

Страница Notibot ещё не создана пользователем. Обмен с настоящим Notibot не проверен: автоматическая проверка выполнена с имитацией родительского окна. Если редактор удаляет script/module либо ограничивает объём HTML, потребуется поддерживаемый Notibot способ загрузки файла или внешняя страница. Текущий Sites-предпросмотр приватный и не предназначен для встраивания посетителям.

Переходы внутри Notibot: через openLink с короткой ссылкой https://t.me/post#ID_СТРАНИЦЫ. ID берётся из access_page_id или purchase_page_id согласно доступу. Внешние startapp-ссылки остаются для автономного открытия вне Notibot. target=_blank удалён. До подтверждения подключения переход блокируется. Реальное сохранение окна проверяется внутри Notibot.
