# Notibot — подключение товаров и проверка оплат (SDK v2.27+)

Отдельный комплект по образцу архива подключения Notibot. Передавайте этот ZIP ИИ вместе с другим проектом, когда нужно связать его материалы/уровни/курсы с товарами Notibot и определять, что пользователь уже оплатил.

Это НЕ библиотека эфиров и НЕ шаблон её дизайна. Здесь нет каталога, фотографий, аккаунтов, ключей и товарных ID конкретного проекта.

## Состав

- `NOTIBOT-PRODUCTS-SKILL.md` — инструкция для ИИ: что подключить и какие методы использовать.
- `docs/QUICK-RECIPES.md` — примеры: один товар, каталог товаров, обновление после оплаты и внутренняя навигация.
- `js/notibot-bridge.js` — неизменённая справочная копия официального SDK v2.27, полученная 7 ноября 2026 года с https://list.notibot.ru/notibot-bridge.js?v=2.27 . В рабочей странице подключайте SDK по официальной ссылке в head, а не локальную копию. Это позволяет не зафиксировать устаревшую версию. Два моста одновременно подключать нельзя.

## Как передавать

Приложите ZIP к новому проекту и напишите:

«Используй комплект Notibot для связи товаров и проверки оплат. Прочитай README.md, NOTIBOT-PRODUCTS-SKILL.md и docs/QUICK-RECIPES.md. Сохрани мой дизайн. Свяжи материалы с реальными product_id магазина. Если ID нет — спроси их, не выдумывай».

## Какие данные нужны от проекта

1. Реальный product_id каждого платного товара из нужного магазина Notibot.
2. Какой материал/уровень открывает этот товар.
3. ID страницы материала и ID страницы покупки, если нужны переходы.

ID товара и ID страницы — разные идентификаторы. Товар используется для проверки оплаты; страница — для навигации. Связи могут быть один товар → один материал или один товар → несколько материалов; это нужно задать в данных проекта.

## Где работает

В любой MiniApp/HTML-странице внутри Notibot, которая получила контекст текущего пользователя и магазина. В другом магазине нужно использовать товарные ID этого магазина. На обычной внешней странице без контекста Notibot покупки пользователя не определяются. Telegram/MAX ID и query string вручную не передаются.

Серверную проверку пользователя и оплаченных товаров обеспечивает Notibot. Этот комплект подключает её к интерфейсу проекта. Сами закрытые материалы также должны быть защищены средствами платформы.
