# Библиотека эфиров Виталия Осокина

Зафиксированная версия: 24 эфира, компактное зеркальное дерево, исходная фотография и обложка, редкие едва заметные звёздочки. Фильтры сохраняют порядок каталога.

## Локальный запуск

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000. Все ресурсы подключены относительными путями; зависимости устанавливать не нужно. Проверка правил каталога: `npm test` с Node.js 20+.

## Тестирование

В браузере вне Notibot доступны тестовые сценарии покупок. Они явно обозначены и не отражают настоящие заказы. Для Notibot скачайте `notibot-library.zip`, распакуйте и вставьте содержимое HTML в страницу; инструкция включена.

Внутри iframe/Notibot демопокупки отключены. Мост Notibot 1.1.0 обеспечивает навигацию и передачу высоты, но не проверяет покупки. Без официальной серверной интеграции оплаченные заказы и подтверждённый профиль не определяются. Клиентские ID не используются для выдачи платного доступа.

Расположение проверено при ширинах 320, 375, 768 и 1280 px. Настоящая страница Notibot ещё не создана; мост проверен с имитацией родительского окна. Актуальность внешних ссылок каталога нужно сверять с Notibot перед запуском для пользователей.
